## 纪律（本站的数据原则）

- **不预测**：只描述已发生的结构与机制，三情景 ≠ 预言
- **标口径**：每个数字带年份 + 来源 + 口径说明
- **不制造焦虑**：每张图都配"不要过度解读"
- **宁缺毋滥**：高校库只收录可核实的变化，暂无记录 ≠ 没有变化
- **粗估标注**：位次区间等为锚点，不是录取线

## 本地运行

纯静态站，无构建步骤。任选其一：

```bash
# Python
python -m http.server 8099
# 然后访问 http://127.0.0.1:8099/index.html
```

或直接双击 `index.html`（图表库已本地化到 `assets/vendor/`，离线可用）。
